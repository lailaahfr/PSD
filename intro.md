# Profil Anda

Halo, saya **Laila Maghfiroh**, mahasiswa aktif semester 5 Program Studi Teknik Informatika di **Universitas Trunojoyo Madura**.

Website ini saya gunakan sebagai media dokumentasi dalam mengerjakan tugas mata kuliah **Proyek Sains Data**. Dalam prosesnya, saya akan mempelajari tahapan pengolahan data, mulai dari memahami permasalahan, mengenali data, melakukan eksplorasi, hingga menyajikan hasil analisis dalam bentuk yang informatif.

Melalui proyek ini, saya berharap dapat memahami bagaimana data dapat diolah dan digunakan untuk memperoleh informasi yang dapat membantu menjelaskan suatu permasalahan.
