Ekstraksi Fitur Deret Waktu Polutan NO₂ Kecamatan Kamal#

Melakukan preprocessing dan ekstraksi fitur pada data konsentrasi nitrogen dioksida (NO₂) di Kecamatan Kamal, Kabupaten Bangkalan. Data yang digunakan mencakup periode 31 Agustus 2025 sampai 31 Agustus 2026.

Tahapan pengolahan data yang dilakukan meliputi pengambilan dan pemeriksaan data, deteksi outlier, penanganan outlier, imputasi missing value, validasi data, serta ekstraksi fitur deret waktu menggunakan library TSFEL (Time Series Feature Extraction Library).

Pengambilan Data#

Data yang digunakan dalam penelitian ini merupakan data konsentrasi polutan NO₂ (Nitrogen Dioksida) pada wilayah Kecamatan Kamal, Kabupaten Bangkalan. Data diperoleh menggunakan platform openEO dengan koleksi data Sentinel-5P L2 dari Copernicus Data Space Ecosystem (CDSE). Pengambilan data dilakukan secara harian pada rentang waktu 31 Agustus 2025 sampai 31 Agustus 2026

    temporal_extent=["2025-08-31", "2026-08-31"],
    spatial_extent={
        "west": 112.6883396,

Deteksi Outlier#

Deteksi outlier dilakukan untuk mengidentifikasi nilai NO₂ yang memiliki penyimpangan cukup jauh dari distribusi data. Metode yang digunakan adalah Interquartile Range (IQR).

Nilai outlier ditentukan berdasarkan batas bawah dan batas atas:

  • Q1 = kuartil pertama (25%)

  • Q3 = kuartil ketiga (75%)

  • IQR = Q3 − Q1

  • Batas bawah = Q1 − 1,5 × IQR

  • Batas atas = Q3 + 1,5 × IQR

Data yang memiliki nilai NO₂ di bawah batas bawah atau di atas batas atas dikategorikan sebagai outlier.

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

df = pd.read_csv("mystorage/N02_Kamal/timeseries.csv")
df['date'] = pd.to_datetime(df['date'])
df = df.sort_values('date').reset_index(drop=True)

# Hitung IQR
Q1 = df['NO2'].quantile(0.25)
Q3 = df['NO2'].quantile(0.75)
IQR = Q3 - Q1

lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

# Filter outlier
outliers_iqr = df[(df['NO2'] < lower_bound) | (df['NO2'] > upper_bound)]

print("Jumlah Outlier (IQR):", len(outliers_iqr))
print(outliers_iqr[['date', 'NO2']].head())

Penanganan Outlier dan Missing Value#

Outlier yang telah teridentifikasi tidak langsung dihapus dari dataset. Nilai tersebut terlebih dahulu ditandai sebagai NaN agar jumlah observasi tetap dipertahankan. Selanjutnya dilakukan proses imputasi untuk mengisi nilai yang kosong. Metode interpolasi linier digunakan untuk memperkirakan nilai berdasarkan data di sekitarnya. Apabila masih terdapat nilai kosong pada bagian awal atau akhir deret waktu, nilai tersebut diisi menggunakan metode backward fill (bfill) dan forward fill (ffill). Dengan proses tersebut, data diharapkan tidak lagi memiliki missing value dan dapat digunakan pada tahap ekstraksi fitur.

# Tandai outlier menjadi NaN
df['NO2_cleaned'] = df['NO2'].mask(
    (df['NO2'] < lower_bound) | (df['NO2'] > upper_bound)
)

# Lakukan interpolasi linier pada NaN yang sudah dibuat
df['NO2_filled'] = df['NO2_cleaned'].interpolate(method='linear')

# Jika masih ada NaN di bagian awal/akhir, isi dengan nilai terdekat
df['NO2_filled'] = df['NO2_filled'].bfill().ffill()

# Buat dataframe hasil akhir
df_no2_kamal = pd.DataFrame({
    "date": df['date'],
    "NO2": df['NO2_filled']
})

# Simpan ke CSV
df_no2_kamal.to_csv("mystorage/N02_Kamal/NO2_Kamal_filled.csv", index=False)

Ekstraksi Fitur Deret Waktu Menggunakan TSFEL#

Setelah data dinyatakan bersih, dilakukan ekstraksi fitur menggunakan TSFEL (Time Series Feature Extraction Library).

Ekstraksi dilakukan terhadap deret waktu polutan NO₂ Kecamatan Kamal. Sebanyak 68 fitur diekstraksi dari data yang telah melalui tahap preprocessing.

Fitur yang dihasilkan mencakup beberapa karakteristik deret waktu, antara lain fitur pada domain Statistical, Temporal, dan Spectral. Hasil ekstraksi kemudian disimpan dalam bentuk file CSV untuk digunakan pada tahap selanjutnya.

import pandas as pd
import numpy as np
import inspect
import tsfel.feature_extraction.features as tsfel_features

# ---------- 1. Muat data yang sudah dibersihkan ----------
df = pd.read_csv('mystorage/N02_Kamal/NO2_Kamal_filled.csv')
df['date'] = pd.to_datetime(df['date'])
df = df.sort_values('date').reset_index(drop=True)

target_pollutant = 'NO2'

# Pastikan data di-casting ke tipe numerik.
df[target_pollutant] = pd.to_numeric(df[target_pollutant], errors='coerce')

# Interpolasi terakhir untuk berjaga-jaga apabila terdapat sisa format nan
df_clean = df.set_index('date').interpolate(method='time').ffill().bfill()
fs = 1
signal_1d = df_clean[target_pollutant].astype(float).values

# Fungsi bantuan (helper) merubah output multivariat TSFEL menjadi float tunggal/skalar
def to_scalar(result):
    if isinstance(result, dict) and "values" in result:
        result = result["values"]
    if isinstance(result, (list, tuple, np.ndarray)):
        arr = np.asarray(result, dtype=float)
        return float(np.nanmean(arr))
    return float(result)

# Fungsi map pemanggilan fungsi TSFEL 
def extract_one(fn_name, signal, fs):
    fn = getattr(tsfel_features, fn_name)
    params = inspect.signature(fn).parameters
    if "fs" in params:
        result = fn(signal, fs)
    else:
        result = fn(signal)
    return to_scalar(result)

# Lakukan ekstraksi iteratif pada fitur
row = {}
for fn_name in FEATURE_LIST:
    row[fn_name] = extract_one(fn_name, signal_1d, fs)

extracted_features_final = pd.DataFrame([row])

print(f"Berhasil! Jumlah fitur yang diekstrak pada {target_pollutant}: {extracted_features_final.shape[1]}")

# Export hasil ke file CSV
extracted_features_final.to_csv(f'mystorage/N02_Kamal{target_pollutant}_Kamal_TSFEL.csv', index=False)

Pengelompokan dan Penjelasan Fitur TSFEL#

Setelah data NO₂ dinyatakan bersih dari outlier dan missing value, dilakukan ekstraksi fitur menggunakan library TSFEL (Time Series Feature Extraction Library). Pada penelitian ini digunakan sebanyak 68 fitur untuk menggambarkan berbagai karakteristik deret waktu konsentrasi NO₂.

Fitur-fitur tersebut dikelompokkan ke dalam tiga domain utama, yaitu Statistical, Temporal, dan Spectral.

1. Statistical Domain#

Statistical Domain berisi fitur yang menggambarkan karakteristik statistik, distribusi, penyebaran, perubahan nilai, serta energi dari data deret waktu.

  1. abs_energy — mengukur total energi atau besarnya nilai sinyal berdasarkan kuadrat nilai-nilainya.

  2. auc — menghitung luas area di bawah kurva deret waktu.

  3. average_power — mengukur rata-rata daya atau energi sinyal.

  4. calc_max — menentukan nilai maksimum dalam deret waktu.

  5. calc_mean — menghitung nilai rata-rata.

  6. calc_median — menentukan nilai tengah atau median.

  7. calc_min — menentukan nilai minimum.

  8. calc_std — menghitung standar deviasi untuk mengetahui tingkat penyebaran data.

  9. calc_var — menghitung varians data.

  10. ecdf — menghasilkan karakteristik distribusi kumulatif empiris dari data.

  11. ecdf_percentile — menentukan persentil berdasarkan distribusi kumulatif empiris.

  12. ecdf_percentile_count — menghitung jumlah data berdasarkan persentil tertentu.

  13. ecdf_slope — menggambarkan perubahan atau kemiringan distribusi kumulatif empiris.

  14. entropy — mengukur tingkat ketidakpastian atau kompleksitas distribusi nilai.

  15. hist_mode — menentukan modus atau nilai yang paling dominan berdasarkan histogram.

  16. human_range_energy — mengukur energi sinyal pada rentang tertentu yang berkaitan dengan rentang pengamatan manusia.

  17. interq_range — menghitung rentang interkuartil atau selisih antara Q3 dan Q1.

  18. kurtosis — menggambarkan tingkat keruncingan distribusi data.

  19. mean_abs_deviation — menghitung rata-rata penyimpangan absolut terhadap nilai pusat.

  20. mean_abs_diff — menghitung rata-rata selisih absolut antar nilai berurutan.

  21. mean_diff — menghitung rata-rata perubahan atau selisih antar nilai.

  22. median_abs_deviation — mengukur penyimpangan absolut median.

  23. median_abs_diff — menghitung median dari selisih absolut antar nilai berurutan.

  24. median_diff — menghitung median perubahan antar nilai berurutan.

  25. mse — menghitung mean squared error atau rata-rata kuadrat kesalahan/perbedaan.

  26. pk_pk_distance — mengukur jarak antara nilai puncak maksimum dan minimum.

  27. rms — menghitung root mean square sebagai ukuran besarnya sinyal.

  28. skewness — menggambarkan kemencengan distribusi data.

  29. slope — mengukur kecenderungan naik atau turun pada deret waktu.

  30. sum_abs_diff — menghitung jumlah seluruh selisih absolut antar nilai berurutan.

2. Temporal Domain#

Temporal Domain berfokus pada pola perubahan data berdasarkan urutan waktu, hubungan antarobservasi, kompleksitas, serta karakteristik struktur temporal pada deret waktu.

  1. autocorr — mengukur korelasi antara nilai deret waktu dengan nilai sebelumnya pada lag tertentu.

  2. dfa — digunakan untuk menganalisis korelasi jangka panjang dan karakteristik fluktuasi pada deret waktu.

  3. distance — mengukur karakteristik jarak atau perubahan sepanjang deret waktu.

  4. hurst_exponent — menggambarkan kecenderungan deret waktu untuk mempertahankan atau membalik pola perubahan sebelumnya.

  5. lempel_ziv — mengukur kompleksitas deret waktu berdasarkan pola atau urutan yang muncul.

  6. maximum_fractal_length — mengukur panjang fraktal maksimum yang terbentuk dari deret waktu.

  7. neighbourhood_peaks — mengidentifikasi karakteristik puncak lokal berdasarkan lingkungan atau titik di sekitarnya.

  8. negative_turning — menghitung karakteristik titik perubahan arah ke arah negatif.

  9. positive_turning — menghitung karakteristik titik perubahan arah ke arah positif.

  10. zero_cross — menghitung jumlah atau karakteristik perpotongan sinyal terhadap nilai nol.

  11. calc_centroid — menentukan pusat massa atau titik pusat distribusi sinyal.

  12. maximum_fractal_length — menggambarkan karakteristik panjang maksimum struktur fraktal pada sinyal.

3. Spectral Domain#

Spectral Domain menganalisis karakteristik data berdasarkan frekuensi. Domain ini digunakan untuk mengetahui distribusi energi, komponen frekuensi, serta karakteristik spektrum dari deret waktu NO₂.

  1. fundamental_frequency — menentukan frekuensi dasar atau frekuensi utama dari sinyal.

  2. max_frequency — menentukan frekuensi dengan nilai atau kontribusi maksimum.

  3. max_power_spectrum — menentukan nilai daya maksimum pada spektrum frekuensi.

  4. median_frequency — menentukan frekuensi median berdasarkan distribusi energi spektrum.

  5. power_bandwidth — mengukur lebar rentang frekuensi yang membawa energi tertentu.

  6. spectral_centroid — menentukan pusat distribusi energi pada spektrum frekuensi.

  7. spectral_decrease — mengukur tingkat penurunan energi spektrum terhadap frekuensi.

  8. spectral_distance — mengukur jarak atau perubahan karakteristik antarbagian spektrum.

  9. spectral_entropy — mengukur tingkat ketidakpastian atau penyebaran energi pada spektrum.

  10. spectral_kurtosis — menggambarkan keruncingan distribusi energi pada spektrum.

  11. spectral_positive_turning — mengidentifikasi karakteristik perubahan arah positif pada spektrum.

  12. spectral_roll_off — menentukan frekuensi batas tempat sebagian besar energi spektrum berada di bawahnya.

  13. spectral_roll_on — menentukan frekuensi awal dari rentang energi spektrum.

  14. spectral_skewness — menggambarkan kemencengan distribusi energi pada spektrum.

  15. spectral_slope — mengukur kemiringan perubahan energi terhadap frekuensi.

  16. spectral_spread — mengukur penyebaran energi di sekitar spectral centroid.

  17. spectral_variation — mengukur perubahan karakteristik spektrum.

  18. spectrogram_mean_coeff — menghitung karakteristik rata-rata koefisien pada spectrogram.

  19. wavelet_abs_mean — menghitung rata-rata nilai absolut koefisien wavelet.

  20. wavelet_energy — mengukur energi yang terdapat pada representasi wavelet.

  21. wavelet_entropy — mengukur kompleksitas atau ketidakpastian distribusi energi pada koefisien wavelet.

  22. wavelet_std — menghitung standar deviasi koefisien wavelet.

  23. wavelet_var — menghitung varians koefisien wavelet.

  24. lpcc — mengekstraksi karakteristik sinyal menggunakan Linear Predictive Cepstral Coefficients.

  25. mfcc — mengekstraksi karakteristik sinyal menggunakan Mel-Frequency Cepstral Coefficients.

  26. higuchi_fractal_dimension dan petrosian_fractal_dimension — mengukur kompleksitas atau dimensi fraktal dari deret waktu.

Ringkasan#

Secara keseluruhan, terdapat 68 fitur TSFEL yang digunakan untuk menganalisis karakteristik deret waktu NO₂. Ketiga domain tersebut memberikan sudut pandang yang berbeda:

  • Statistical → menggambarkan nilai, distribusi, penyebaran, dan perubahan statistik data.

  • Temporal → menggambarkan pola, hubungan antarwaktu, kompleksitas, dan perubahan arah deret waktu.

  • Spectral → menggambarkan karakteristik frekuensi, distribusi energi, spektrum, serta representasi wavelet.

Hasil ekstraksi 68 fitur kemudian disimpan dalam file CSV dan digunakan sebagai data masukan untuk tahap penyimpanan ke database Aiven.
