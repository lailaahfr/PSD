# Analisis Polutan Udara di Kamal, Bangkalan

Proyek ini membahas analisis data polutan udara di wilayah **Kamal** dengan memanfaatkan data pengamatan satelit **Sentinel-5P**. Data diakses melalui **Copernicus Data Space Ecosystem** dan layanan **openEO**, kemudian diolah menggunakan pendekatan sains data untuk mempelajari karakteristik dan pola yang terdapat pada data polutan.

Analisis berfokus pada tiga polutan, yaitu **nitrogen dioksida (NO₂)**, **sulfur dioksida (SO₂)**, dan **karbon monoksida (CO)**. Proses pengerjaan dilakukan secara bertahap mulai dari memahami permasalahan, mengenali data, mengambil dan mengolah data berbasis cloud, mengekstraksi fitur, hingga melakukan analisis clustering.

Setiap bagian menyajikan penjelasan konsep, tahapan pengerjaan, kode program, dan interpretasi hasil agar proses analisis dapat diikuti secara sistematis.
